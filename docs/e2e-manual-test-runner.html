Papan uji E2E manual

Suka Shawarma — hulu ke hilir, semua role · klik baris untuk lihat hasil diharapkan
Tentang & lingkungan uji
  • Penguji manusia, semua app web. Mobile native (native-superapp/native-pos/pos-mobile) di-exclude.
  • Port lokal: portal 3010, stok 3001, distribusi 3002, owner 3003, pos-kasir 3004, admin 3005, absensi 3006.
  • Semua data uji berprefix E2E — jangan sentuh data outlet nyata. DB remote dipakai bersama.
  • Wajib uji build produksi (yarn build && yarn start) untuk S0 + semua halaman detail — regresi RSC 500 tak muncul di yarn dev.
  • Kerjakan berurutan: alur menyambung (barang PO di S1 mengalir sampai laporan S10). Detail lengkap: docs/E2E-MANUAL-TEST-PLAN.md.
