Edge Functions: Cold Starts & Serverless Errors

Edge Functions menjalankan logic rahasia di server terdekat dengan user. Mari kita pelajari cara deploy, troubleshoot, dan log fungsinya.

🎯 Tujuan Lesson Ini

  • Memahami apa itu Deno Runtime dan serverless architecture
  • Memahami konsep Cold Start dan cara meminimalkannya
  • Bisa membaca log error Edge Function di dashboard Supabase
  • Bisa men-deploy Edge Function baru secara aman

1. Apa itu Edge Functions?

Edge Functions di Supabase adalah fungsi serverless yang berjalan di atas Deno (runtime JavaScript/TypeScript modern yang sangat cepat) di jaringan CDN global. Artinya, kode kamu dieksekusi di server fisik terdekat dengan karyawan outlet yang sedang mengakses aplikasi.

Fungsi yang Ada di SS Digital

Kamu memiliki 14 fungsi di folder supabase/functions/. Contoh kunci:

  • submit-attendance: Memproses absensi selfie crew, memverifikasi koordinat GPS, dan mencocokkan wajah.
  • send-push: Mengirim notifikasi push ke handphone manager/owner saat ada pengajuan kasbon atau stok menipis.
  • webhook-sync-order: Menangkap sinyal order masuk dari sistem Ecosystem luar untuk dimasukkan ke database utama.

2. Fenomena "Cold Start"

Karena arsitekturnya *serverless* (tanpa server tetap), Supabase akan "mematikan" kontainer fungsimu jika tidak ada yang memanggilnya selama beberapa menit untuk menghemat memori.

Saat fungsi dipanggil kembali setelah lama menganggur, akan terjadi **Cold Start**: Kontainer Deno harus dinyalakan kembali, mendownload library dependency, baru mengeksekusi request.

[User Klik Absen] ──▶ [Edge Function (Tidur)] ──▶ Menyalakan Kontainer (Cold Start: 1-3 detik) ──▶ Eksekusi (Warm Run: 50-100ms)
💡 Tips Mengurangi Latency Cold Start

Jangan meng-import dependency yang terlalu besar di awal file jika tidak dibutuhkan. Gunakan file import_map.json terpusat untuk memetakan dependency versi spesifik agar Deno bisa men-cache dependency tersebut dengan efisien.

🩺 Cara Membaca Log & Mengatasi Error

Saat Edge Function gagal (misalnya notifikasi push tidak terkirim), kamu tidak akan melihat errornya di browser kasir. Kamu harus memeriksanya di dashboard:

📍 Cara Buka Log Edge Functions
  1. Buka Supabase Dashboard → Edge Functions
  2. Pilih fungsi yang bermasalah (misalnya send-push)
  3. Klik tab Logs
  4. Gunakan filter level Error untuk langsung melompat ke tumpukan crash log
⚠️ CORS Errors: Masalah Paling Klasik

Jika konsol browser menampilkan error merah CORS policy blocked..., itu bukan masalah jaringan, melainkan Edge Function kamu crash di tengah jalan sebelum sempat mengirimkan HTTP Response Header (headers CORS). Selalu bungkus logic Edge Function kamu dalam blok try { ... } catch (err) { ... } dan kembalikan response header CORS yang tepat pada blok catch agar browser tidak memblokir pesan error aslinya!

🚀 Cara Deploy Update Edge Function

Jika kamu melakukan perubahan pada kode fungsi lokal di komputermu, jalankan command berikut di terminal untuk memperbaruinya di cloud:

# Deploy satu fungsi spesifik (disarankan)
supabase functions deploy [nama-folder-fungsi]

# Contoh:
supabase functions deploy send-push

# Catatan: Pastikan kamu sudah login CLI menggunakan `supabase login`
