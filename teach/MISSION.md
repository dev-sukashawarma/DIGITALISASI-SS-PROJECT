# Mission: Backend Infrastructure untuk Suka Shawarma Digital Suite

## Why
Kamu sudah membangun sistem operasional untuk 19 outlet Suka Shawarma lewat vibe coding —
hasilnya nyata dan berjalan. Sekarang kamu perlu memahami *mengapa* hal-hal bekerja,
apa yang bisa rusak, dan bagaimana menjaganya tetap cepat, aman, dan stabil — supaya kamu
bisa merawat sistem ini sendiri tanpa harus menebak-nebak setiap kali ada masalah.

## Success looks like
- Bisa membaca query SQL yang lambat dan tahu cara mempercepatinya
- Bisa menjelaskan cara kerja Row Level Security (RLS) dan mengapa itu penting
- Bisa mendeteksi dan memperbaiki masalah performa database di Supabase dashboard
- Bisa memutuskan kapan butuh index, materialized view, atau caching
- Bisa menjaga Edge Functions tetap efisien dan tidak bocor memori
- Bisa merespons insiden (sistem down, data error) dengan tenang dan metodis

## Constraints
- Belajar dari project nyata sendiri (SS Digital Suite) — semua contoh harus relevan
- Tidak perlu belajar dari nol teori CS — fokus ke praktik yang langsung bisa dipakai
- Bahasa Indonesia, dengan istilah teknis Inggris yang dijelaskan saat pertama muncul
- Sesi per topik — jangan overwhelm sekaligus

## Out of scope
- DevOps server Linux murni (kita di cPanel/Supabase managed)
- Kubernetes, Docker Swarm, cloud self-hosting
- Replikasi database manual / sharding
