Kebijakan Privasi Suka Admin

Berlaku sejak 25 November 2026 · Suka Shawarma

Untuk siapa aplikasi ini

Suka Admin adalah aplikasi internal untuk pemilik dan staf manajemen Suka Shawarma. Aplikasi ini menampilkan laporan bisnis (penjualan, laba rugi, beban operasional) dan hanya dapat dipakai oleh akun staf yang sudah terdaftar di sistem Suka Shawarma.

Data yang kami gunakan

  • Alamat email/username dan ID akun — untuk masuk dan menentukan laporan apa yang boleh Anda lihat sesuai peran Anda.
  • Data laporan bisnis Suka Shawarma — dibaca dari server kami saat Anda membuka laporan.

Kami tidak mengumpulkan lokasi, kontak, foto, data kesehatan, atau data pribadi lain. Kami tidak memakai iklan, pelacakan, atau analitik pihak ketiga, dan tidak menjual atau membagikan data kepada pihak lain.

Penyimpanan di perangkat

Untuk mempercepat tampilan, aplikasi menyimpan salinan laporan terakhir dan pengaturan (misalnya filter periode dan pilihan tampilan) di perangkat Anda. Token masuk disimpan di Keychain iOS. Semua data ini dihapus saat Anda keluar dari aplikasi atau menghapus aplikasi.

Face ID

Bila Anda menyalakan kunci Face ID, verifikasi wajah dilakukan sepenuhnya oleh iOS di perangkat Anda. Aplikasi tidak menerima atau menyimpan data wajah.

Keamanan

Data dikirim melalui koneksi terenkripsi (HTTPS). Akses ke laporan dibatasi oleh peran akun Anda di server.

Hak Anda

Akun staf dikelola oleh admin Suka Shawarma. Untuk meminta penghapusan akun atau bertanya tentang data Anda, hubungi kami di dev.sukashawarma@gmail.com.

Perubahan kebijakan

Bila kebijakan ini berubah, versi terbaru akan dimuat di halaman ini beserta tanggal berlakunya.
